Bot para WhatsApp em Node.js com IA generativa (Google Gemini), criador de stickers e mini-games.

- Persona com IA (!gpt): Conversar com o bot simulando um personagem.
- Gerador de Stickers (!s): Converte imagem em sticker (enviar na legenda).
- Mini-game de Roleta (!roleta / !ranking): Mini-game de sorte com placar.

---

### Pré-requisitos
- Node.js instalado.
- Uma chave de API da Gemini (Google AI Studio).

### Crie um arquivo ".env" na raiz com a chave de API:
GEMINI_API_KEY=sua_chave_aqui
